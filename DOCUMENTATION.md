__Windows__

To create a window, call _mkwin()_ and assign its output to a window struct so that you can access the window again in your program.

A freshly made window will have default properties assigned to it. To modify these properties before using the window, or at any point during runtime, call the corresponding function and provide a pointer to your window struct alongside the needed arguments.
ALL FUNCTIONS TO MODIFY A WINDOW:
	_modwinbg()_
